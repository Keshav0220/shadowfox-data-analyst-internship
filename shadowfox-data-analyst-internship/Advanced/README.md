# 🎬 Netflix Data Analysis Project

## 📌 Project Overview

This project analyzes Netflix's dataset to uncover insights about content distribution, trends, and user preferences.

The analysis includes **data cleaning, feature engineering, exploratory data analysis (EDA), and visualization** using Python.

---

## 🚀 Tools & Technologies

* 🐍 Python (Pandas, NumPy)
* 📊 Matplotlib & Seaborn
* 📁 Jupyter Notebook / VS Code
* 📈 Power BI (for dashboard)

## 🧹 Data Cleaning

* Removed duplicate records
* Handled missing values (director, cast, country)
* Converted `date_added` to datetime
* Extracted year, month, and day
* Cleaned and standardized categorical data

---

## 📊 Key Analysis Performed

### 🔹 Content Distribution

* Movies vs TV Shows
* Most common ratings

### 🌍 Country Analysis

* Top 10 content-producing countries
* Country vs content type

### 🎭 Genre Analysis

* Most popular genres
* Genre distribution across Movies & TV Shows

### 📅 Time Analysis

* Year-wise content growth
* Month with highest content addition
* Weekday vs Weekend trends

### ⏱️ Duration Analysis

* Average duration of movies

---

## 📈 Key Insights

* 🎬 Movies dominate Netflix content
* 📈 Massive growth after 2015
* 🌍 USA is the largest content producer
* 🎭 Drama & Comedy are most popular genres
* ⭐ TV-MA is the most common rating
* 📅 Most content added during specific peak months
