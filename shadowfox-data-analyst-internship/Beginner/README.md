# 📊 Retail Sales Dashboard — Excel

## 📌 Project Overview

This project is a **Retail Sales Analysis and Interactive Dashboard** developed entirely in **Microsoft Excel**.

The objective of this project is to analyze retail sales performance across different cities and sales executives, track key performance indicators, identify trends, and present the findings through an interactive and easy-to-understand dashboard.

The project demonstrates the complete basic data-analysis workflow:

**Raw Data → Data Cleaning → Analysis → KPIs → Visualization → Dashboard → Business Insights**

---

## 🎯 Business Objective

The dashboard is designed to help a business understand:

- Overall sales performance
- City-wise sales performance
- Sales Executive performance
- Target achievement
- Sales gaps against targets
- Trends and variations in sales
- Performance across different business segments

The analysis can help management identify strong-performing areas and sales executives while highlighting areas that may require improvement.
